# DramaFlix

Site para descobrir e comentar dramas, com resenhas da comunidade e um espaço para os usuários indicarem seus dramas favoritos.

## Funcionalidades

Página inicial de apresentação do site. Seção de resenhas de dramas. Página Conta Mais para os usuários compartilharem indicações.

## Tecnologias utilizadas

HTML5, CSS3 e JavaScript.

## Como executar

Clone este repositório e abra o arquivo pag/index.html no navegador, que é a página inicial do site.
